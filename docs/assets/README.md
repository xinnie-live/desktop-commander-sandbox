# Demo assets / 演示素材

Updated 2026-11-15. `demo.gif` is English; `demo.zh-CN.gif` is Simplified Chinese. Both are 4K UHD (3840 × 2160, 16:9), four frames lasting 3, 4, 3, and 3 seconds (13 seconds per loop). These are narrated screenshot walkthroughs, not continuous live recordings.

The 4K edition uses fresh lossless PNG browser captures at a device pixel ratio of 3, with text and summary graphics rendered directly at the output resolution. It does not upscale the previous GIF or its JPEG source captures. The README displays a scaled preview; open the GIF or linked PNGs for full-resolution inspection.

The overview, image preparation, and workspace editor were captured from the actual current local console using dedicated synthetic folders. Only host paths were covered; modal screenshots were cropped to their dialogs. No device was started or paired for this photography session. The console is correctly shown stopped with an existing image.

The final acceptance-summary panel is an editorial summary of the recorded 2026-11-15 Mac + OrbStack run: input alpha/beta, report {"lines":2}, read-only rejection EROFS, and persistence after stop/restart. It is labeled as recorded evidence, not a newly executed remote call or a product screen. Windows and published-image downloads are not claimed as verified.

`overview-*.png`, `prepare-*.png`, and `workspace-*.png` are the full-resolution stills. `acceptance-summary-*.png` are summary graphics. Raw screenshots, logs, and the local reproduction script are excluded from the public package. Public assets contain no account information, device codes, session links, or host absolute paths.
